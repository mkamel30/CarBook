## Review Guidelines

Review the codebase against [docs/PRD.md](../docs/PRD.md), [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md), and [docs/SECURITY.md](../docs/SECURITY.md).

For every finding, format as:
- **Severity:** High / Medium / Low / Note
- **Evidence:** Exact code reference or command output
- **Affected File:** Relative path
- **Reproduction Steps:** How to trigger or observe
- **Recommended Fix:** Clear technical remedy
- **Verification Method:** How to verify the fix
- **Certainty:** Confirmed or Tentative

Do not force a minimum number of findings if the code is solid.
