## 🌟 نظرة عامة

**CarBook** هو تطبيق ويب محلي الصنع وفائق الدقة، مصمم خصيصاً لمساعدة ملاك السيارات وقائدي المركبات على متابعة استهلاك الوقود ومصاريف الصيانة الدورية وقطع الغيار والتنبيهات المعتمدة على قراءة العداد (Odometer).

تم بناء التطبيق وفق مفهوم **العمل المحلي أولاً (Offline-First)** دون أي اعتماد إجباري على خوادم سحابية، مع دعم كامل للغتين **العربية** و **الإنجليزية** وتحكم ديناميكي في اتجاه الواجهة (**RTL / LTR**) بفضل محرك ملفات الـ **`.cfg`** المبتكر.

## 🚀 أبرز المميزات

### ⛽ 1. سجل الوقود وحساب الاستهلاك الدقيق
- **احتساب ثنائي الاتجاه:** بمجرد إدخال كمية الوقود باللترات يتم حساب المبلغ تلقائياً، وبمجرد إدخال المبلغ يتم حساب اللترات تلقائياً بدقة الكسور العشرية (مثل `40.584` لتر).
- **مقارنة التفويلات المتتالية:** حساب دقيق لمعدل استهلاك اللتر لكل 100 كم ($L/100\text{km}$) ومعدل الكيلومتر لكل لتر وتكلفة الكيلومتر الواحد بالجنية.
- **تعديل ديناميكي مرن:** إمكانية تعديل أو حذف أي تفويلة قديمة مع إعادة احتساب استهلاك التفويلات اللاحقة تلقائياً.
- **جدول أسعار الوقود في الإعدادات:** حفظ أنواع وأسعار البنزين والوقود (بنزين 92، بنزين 95، سولار، غاز طبيعي) وتذكر آخر خيار تلقائياً.

### 🔧 2. سجل الصيانات وتفصيل قطع الغيار
- **إضافة أكثر من قطعة غيار في الفاتورة الواحدة:** تسجيل كل قطعة غيار مع تحديد حالتها (**جديد أصلي** أو **استيراد/مستعمل بحالة ممتازة**) وسعرها.
- **جمع آلي للتكاليف:** جمع تلقائي لـ (إجمالي قطع الغيار + المصنعية = الإجمالي الكلي).
- **توثيق المراكز والورش:** حفظ اسم مركز الخدمة وتحديد قراءة العداد المستهدفة للصيانة القادمة.

### ⚠️ 3. جدول الصيانة الوقائية والتنبيهات الذكية
- **تنبيهات فورية ملونة:** تصنيف حالة كل صيانة دورية تلقائياً:
  - **حالة جيدة (Good):** العداد المتبقي آمن.
  - **مستحقة قريباً (Due Soon):** بقي أقل من 1,000 كم أو شهر على الموعد.
  - **متأخرة وتجاوزت الموعد (Overdue):** تجاوزت قراءة العداد الفاصل الموصى به.
- تنبيهات زمنية وبالكيلومتر في نفس الوقت.

### 📖 4. كتالوج ومواصفات المصنع الأصلية (OEM Specs) بالذكاء الاصطناعي
- **استخراج وحفظ محلي للمواصفات الفنية المعتمدة:**
  - لزوجة زيت المحرك المعتمدة (مثل `0W-20` أو `5W-30`) وسعة الزيت مع الفلتر.
  - نوع زيت الفتيس وناقل الحركة (CVT / ATF).
  - نوع مياه الردياتير وسائل التبريد وسائل الفرامل (DOT 4).
  - ضغط هواء الإطارات الموصى به للعجلات الأمامية والخلفية (PSI / Bar).
  - سعة خزان الوقود (التانك) والأوكتان الموصى به للبنزين.
  - شمعات الاشتعال (البوجيهات) ومواصفة البطارية.

### 👨‍🔧 5. استشارة طبيب الصيانة الذكي (AI Car Doctor)
- **تشخيص مبني على بيانات سيارتك الواقعية:** استشر مهندس الصيانة المساعد حول أي أعراض غريبة، أو أصوات طقطقة، أو أكواد أعطال (مثل `P0420` أو `P0300`).
- لا يقدم إجابات عشوائية، بل يربط الذكاء الاصطناعي استشارتك بـ:
  1. قراءة العداد الحالية (كم).
  2. أحدث عمليات الصيانة وتغيير الزيت المسجلة لسيارتك.
  3. الموديل وسنة الصنع والمواصفات المصنعية.

### 📄 6. تقرير الفحص والبيع المعتمد
- **تقرير جاهز للطباعة وتصدير PDF:** تقرير معتمد ونظيف يثبت للمشتري قراءة العداد الحقيقية وجميع الصيانات التي تمت وقطع الغيار المركبة بشفافية كاملة.

### 🌐 7. نظام اللغات المتعددة المعتمد على ملفات `.cfg`
- **ترجمة خالية من التعقيد:** جميع نصوص النظام محفوظة في ملفات إعدادات بسيطة وسهلة القراءة داخل مجلد [`src/locales/`](src/locales/):
  - [`ar.cfg`](src/locales/ar.cfg): النسخة العربية الكاملة (`dir = rtl` وبخط القاهرة الجميل).
  - [`en.cfg`](src/locales/en.cfg): النسخة الإنجليزية المعتمدة (`dir = ltr`).
- **إضافة أي لغة جديدة بدون كتابة كود:** يمكن لأي شخص نسخ ملف `en.cfg` وتسميته `fr.cfg` أو `de.cfg` وترجمة الأسطر في المفكرة العادية ليتم تفعيلها فوراً.

## 🛠️ التثبيت والتشغيل المحلي

### المتطلبات الأساسية
- تثبيت **Node.js** بإصدار 18 فما فوق.
- استخدام مدير الحزم **pnpm** (المفضل) أو **npm**.

### خطوات التشغيل:

1. **استنساخ المستودع (Clone):**
   ```bash
   git clone https://github.com/mkamel30/CarBook.git
   cd CarBook
   ```

2. **تثبيت الاعتماديات:**
   ```bash
   pnpm install
   ```

3. **بدء السيرفر المحلي:**
   ```bash
   pnpm dev
   ```

4. **فتح التطبيق في المتصفح:**
   افتح الرابط: [http://localhost:3070](http://localhost:3070).

للتأكد من سلامة جميع الحسابات البرمجية ومطابقة الأنواع:

```bash
# تشغيل جميع اختبارات الوحدات والتكامل الآلية

# فحص أنواع TypeScript
pnpm typecheck
```

## 🔒 الخصوصية والأمان

- **بياناتك ملكك بالكامل:** تحفظ جميع السجلات محلياً في ملف SQLite (`local.db`) على جهازك الشخصي.
- **بدون تتبع:** التطبيق لا يحتوي على أي كود تتبع أو جمع بيانات أو إعلانات.
- **حماية المفاتيح السرية:** مفاتيح الذكاء الاصطناعي تخزن محلياً بأمان ولا يتم تضمينها في ملفات الواجهة أو مستودع Git.
