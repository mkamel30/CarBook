# Deployment and Run Guide

**Project:** Car Maintenance Followup
**Date:** 2026-10-28T12:01:50.318Z

## Target Environment

- **Environment:** local_only

## Run Instructions

1. Inspect `package.json` to verify installed dependencies and configured scripts.
2. Verify package manager (`packageManager` in `package.json` or single lockfile) before installing.
3. Install dependencies using the verified package manager (e.g. `pnpm install` or `npm install`).
4. Run the development server as configured in `package.json` scripts.
5. Execute test suite before making changes.
